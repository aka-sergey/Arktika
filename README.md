# АРКТИКА · завод воды — бизнес-игра

Интерактивная финансовая модель завода по очистке и розливу воды в Иваново на 26 месяцев (ноябрь 2026 — декабрь 2028). Цель игры — окупить проект до декабря 2028 при минимальных вложениях инвестора.

## Как открыть

- `index.html` — вся игра в одном файле. Откройте в браузере или включите GitHub Pages для ветки `main`.
- Нужен интернет: шрифты и библиотека ExcelJS подгружаются с CDN.
- Сценарии и журнал ходов хранятся в браузере (localStorage) — у каждого участника свои.

## Сценарии участников на Netlify

Сайт на Netlify (`netlify.toml`) включает функцию `netlify/functions/scenarios.mjs`: она хранит сценарии посетителей в Netlify Blobs и отдаёт их всем.

- Посетитель: вкладка «Сценарии» → название, имя → «Опубликовать сценарий с экрана». Сценарий сразу виден всем, ссылка на него короткая (`#id=…`).
- Чужой сценарий можно открыть и играть от него; изменить или удалить нельзя.
- Переменные окружения сайта (Project configuration → Environment variables), после изменения нужен новый деплой:
  - `TEAM_CODE` — код команды. Если задан, публиковать можно только с ним; если нет — публикация открыта всем.
  - `ADMIN_CODE` — код владельца, чтобы убирать сценарии с сайта. Если не задан, удаление выключено.
- На GitHub Pages функции нет: там работают только файл `scenarios.json`, ссылки и личные сценарии в браузере.
- Проверка логики функции без Netlify: `node tests/test_function.mjs`.

## Общие сценарии из файла

- `scenarios.json` в корне — сценарии, которые видит каждый, кто открыл страницу (список «Общие — видят все»).
- Свои сохранённые сценарии каждый посетитель хранит в браузере; чужих он не видит.
- Опубликовать сценарий для всех может владелец: вкладка «Сценарии» → вставить токен GitHub → «Сделать общим». Токен — fine-grained, только на этот репозиторий, право Contents: Read and write; хранится только в браузере владельца.
- Без токена: «Скачать мои сценарии файлом» и загрузить файл как `scenarios.json` через «Add file → Upload files».
- «Ссылка на сценарий с экрана» — сценарий целиком зашит в ссылку, сервер не нужен.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | Собранная игра (самостоятельная страница) |
| `scenarios.json` | Общие сценарии из файла, видимые всем посетителям |
| `netlify/functions/scenarios.mjs`, `netlify.toml`, `package.json` | Сервис сценариев участников на Netlify |
| `src/engine.js` | Расчётное ядро: сценарий → расчёт по месяцам и по дням |
| `src/meta.js` | Справочник параметров: подписи, единицы, группы |
| `src/excel.js` | Выгрузка сценария в Excel с формулами (ExcelJS) |
| `src/ui.js`, `src/style.css`, `src/body.html` | Экран игры |
| `src/build.py` | Сборка: `python3 build.py` в папке `src` |
| `tests/` | Сверка ядра с Excel-моделью V7 и сверка выгрузки Excel с ядром |
| `models/` | Excel-модель V7 и пример выгрузки базового сценария из игры |

## Правила расчёта коротко

- Мощность = сумма по типам установок (ТИП-А30, ТИП-Б130): штук × литров в сутки × коэффициент использования × дни.
- Завод разливает по плану продаж плюс целевой запас, но не больше мощности воды и линии розлива.
- Материалы (крышки, преформы, этикетки, паллеты, стрейч-плёнка) покупаются партиями заранее; в расходы попадают при розливе, деньги уходят при оплате партии.
- Инвестор вносит ровно столько, чтобы в конце месяца на счёте остался неснижаемый остаток.
- Окупаемость — месяц, когда накопленный денежный поток без денег инвестора стал неотрицательным.
- Налоги упрощённо: УСН 5 % от прибыли месяца (минимум 1 % поступлений), НДС 5 % после 20 млн ₽ поступлений с начала года.

Полные правила — во вкладке «Правила игры» внутри страницы.

## Проверка

```
cd tests
node test_engine.js                 # ядро против Excel-модели V7
npm install exceljs@4.4.0
node test_excel.js                  # выгрузка 11 сценариев в xlsx
python3 cmp_excel.py                # пересчёт в LibreOffice и сверка с ядром (нужен скрипт пересчёта)
```

## Допущения, которые нужно уточнить

- Оклады по ролям — разложение общего ФОТ, не факт.
- Размеры бутылок, цена паллеты и стрейч-плёнки — оценки.
- Пресс-формы бутылок и транспорт крышек — нули, данных нет.
- Цена установки ТИП-Б130 не подтверждена поставщиком.
- Коэффициент взносов на зарплату 1,13 — проверить у бухгалтера.
